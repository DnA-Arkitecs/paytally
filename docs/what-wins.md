# What wins a hackathon like this

From past Devpost winners and judging notes (PayPal, AG Grid and agentic-commerce events, read Oct 22, 2026). PayTally is built to meet each line.

1. **Judges can use it in a minute.** A hosted link with no sign-in, a numbered tour on the first screen, and a real number on the page.
2. **One real pain, sized in dollars, for one kind of person.** The agency owner who bills per result and spends month-end reconciling.
3. **The model reads; plain code decides the money.** Every change to money waits for a person's click, and the demo shows where.
4. **Every output carries its proof.** Each line names its source rows, and what was not billed (and why) is shown as plainly as what was.
5. **Measured, with honest misses, and a protocol story on camera.** Evals with their failures written down, and a second company's AI agent auditing, disputing and paying over MCP.
